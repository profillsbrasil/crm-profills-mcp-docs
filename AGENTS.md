# AGENTS.md

Este repositório é a documentação pública do conector MCP do CRM da Profills e o plugin `crm-profills` do Claude e do Codex. Não há código para rodar.

- Para instalar o CRM para o vendedor, siga [INSTALAR.md](INSTALAR.md).
- Para usar o CRM pelo vendedor, leia [docs/agentes.md](docs/agentes.md).
- Para conectar, refazer o login ou tirar servidor duplicado, siga a skill [crm-profills-conexao](skills/crm-profills-conexao/SKILL.md).
- `docs/tools.md` sai do script do servidor. Nunca edite essa página à mão.

O login no CRM e o clique em permitir são sempre do vendedor.
